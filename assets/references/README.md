# Visual Reference Catalog

These 41 screenshots are design research from Tower Defense Simulator. They are **not runtime assets** and must never be imported, shipped, traced, cropped, recolored, or closely reproduced. Use them only to identify general usability ideas and then create original designs.

Files use descriptive names so agents can open only the relevant references instead of scanning unrelated screenshots.

## Approved Abstract Takeaways

- Give major lobby destinations distinct silhouettes, lighting colors, and large readable signs.
- Keep frequently used actions and loadout status visible without hiding the 3D environment.
- Group large collections with categories, search/filter controls, locked-state clarity, and a focused detail panel.
- Show map/mode choices as scannable cards with selection confirmation and readiness feedback.
- During battle, prioritize base health, wave progress, currency, tower choices, selected-tower details, boss health, and clear outcomes.
- Blur/dim world content behind modal UI enough to preserve focus while retaining context.

## Do Not Copy

- Tower or enemy character designs
- Names, lore, dialogue, descriptions, numbers, or progression requirements
- Logos, icons, typography treatment, color combinations, exact panel geometry, or screen composition
- Maps, lobby architecture, portal facades, thumbnails, models, textures, animations, effects, or sounds
- Roblox avatars, player names, leaderboards, or other incidental identifying content
