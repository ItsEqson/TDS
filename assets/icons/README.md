# Original interface artwork

All SVG portraits and icons are original procedural vector artwork created for Copper Reach. Source role labels map the requested brainstorm to original characters; no reference screenshots or external game assets are used. World characters remain procedural Three.js geometry.

Color/detail pass: `scripts/enrich_art.py` adds original vector gradients, highlights and equipment markings to all portraits and symbols. No external artwork or raster reference material is incorporated.
